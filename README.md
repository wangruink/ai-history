# 人工智能发展简史 · 高中通识课（Reveal.js 演示文稿）

面向高中生的一小时 AI 通识课：AI 历史 + CNN 原理 + Transformer 原理，共 **39 页**，每页均附有**演讲者讲稿（备注）**。

## 快速开始

1. **双击 `index.html`**（推荐 Chrome / Edge 浏览器打开），无需联网、无需安装任何东西（reveal.js 已下载到本地 `reveal/` 文件夹）。
2. 按 `F` 进入全屏即可开始上课。

## 放映快捷键

| 按键 | 功能 |
|---|---|
| `←` `→` / 空格 | 上一页 / 下一页 |
| `F` | 全屏放映 |
| `S` | **演讲者视图**（含每页讲稿、下一页预览、计时器） |
| `O` / `Esc` | 缩略图总览，快速跳页 |
| `Alt+点击` | 放大镜查看细节（zoom 插件） |

## 课件结构（约 60 分钟）

| 幕 | 页码 | 内容 | 建议用时 |
|---|---|---|---|
| 开场 | 1–3 | 封面、旅程地图、热身互动 | 3 min |
| 第一幕 · AI 历史 | 4–13 | 图灵测试 → 达特茅斯 → 两次寒冬 → 深蓝 → 机器学习 → AlexNet → AlphaGo → 大模型时代 | 18 min |
| 第二幕 · CNN | 14–24 | 像素 → 神经元 → 网络与训练 → 卷积（**动画演示**）→ 池化 → 层层抽象 → 应用 | 18 min |
| 第三幕 · Transformer | 25–35 | 语言难题 → RNN 困境 → 注意力（**热力图**）→ Q/K/V → 多头 → 架构 → BERT/GPT → 下一词预测 → 规模定律 | 18 min |
| 尾声 | 36–39 | 70 年时间线、AI 的能与不能、行动清单、Q&A | 6 min + 问答 |

## 演讲者讲稿

每一页的 `<aside class="notes">` 里都写好了：讲法要点、互动设计（如"迷你图灵测试"、口算卷积）、时间提示。
放映时按 `S` 打开演讲者视图即可边看讲稿边讲；也适合把课件直接交给他人代讲。

## 导出 PDF（讲义版）

在浏览器地址栏打开 `index.html?print-pdf`，然后 `Ctrl+P` → 目标选"另存为 PDF" → 布局"横向" → 勾选"背景图形" → 保存。

## 修改与扩展

- 每一页是一个 `<section>`，直接改文字即可；颜色主题集中在文件开头的 `<style>` 中（`--cnn` 青、`--tf` 金、`--hist` 紫、`--end` 粉）。
- 卷积动画、注意力热力图、像素"7"由文件末尾的小段 JavaScript 生成，数据（输入矩阵、卷积核、注意力权重）就写在函数开头，方便替换成你自己的例子。
